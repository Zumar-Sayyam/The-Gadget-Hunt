# 🎮 The Gadget Hunt

*A fun Snap! game inspired by Doraemon, where players collect falling gadgets and avoid mice!*

---

## 📖 About the Game

Step into Doraemon’s shoes in **The Gadget Hunt** — a fast-paced arcade-style game where your goal is to catch falling gadgets and avoid pesky mice! Inspired by the popular Doraemon episode *"Nobita and the Gadget Museum"*, this project was designed to mix fun, creativity, and coding.

---

## 🎮 How to Play

* **Move Doraemon** using the **arrow keys**

 * **Catch gadgets** to **earn points**

 * **Drop a gadget?** You’ll **lose a life**

 * **Touch a mouse?** That’s another **life lost**

 * **Catch a heart** to **gain back a life**

 * **Game Over** if you lose **3 lives**!

## 🖥️ How to Open the Project

1. Go to [Snap!](https://snap.berkeley.edu/)
2. Click on **File > Import...**
3. Select the file `The Gadget Hunt.xml`

📁 *(Make sure your `.xml` file is saved locally)*
